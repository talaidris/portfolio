LAPTOP ARTWORK
Drop laptop-specific images in this folder, then point to them in js/config.js
(the "laptop" section). Anything you leave as null falls back to the phone image.

  wallpaper      2560x1600 (16:10), landscape            -> SITE_IMAGES.laptop.wallpaper
  dock icons     square, 256x256 or larger (png/jpg)     -> SITE_IMAGES.laptop.icons.<app>
  project images wide, 1280x720 (16:9)                   -> SITE_IMAGES.laptop.projects.<project>

Project ids: aiaa, misa, movies, draw
App ids:     experience, education, skills, projects, messages, music, photos,
             notes, weather, calculator, todo, books
